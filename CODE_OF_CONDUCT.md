# Code of Conduct

## Our Standards

This project expects practical, respectful collaboration. Good contributions are
clear about evidence, hardware tested, and remaining uncertainty.

Unacceptable behavior includes harassment, personal attacks, deliberate
misrepresentation of mining results, and sharing another person's private
configuration or wallet information.

## Enforcement

Maintainers may remove comments, issues, pull requests, or contributors that
make the project unsafe or unproductive. Enforcement decisions should be based
on observed behavior and documented project needs.

## Scope

This code of conduct applies to project repositories, issue trackers, pull
requests, discussions, and other official project spaces.
